Persistence		,Permanent (until manually deleted)	,Until the tab is closed	,Depends on set expiry date
Sent to Server,		No					,No				,Yes (with every HTTP request)
Scope			,Same origin (all tabs/windows)	 	,Current tab only		,Domain & Path specific
Security		,Vulnerable to XSS			,Vulnerable to XSS	 	,"Better (can use HttpOnly, Secure)"
